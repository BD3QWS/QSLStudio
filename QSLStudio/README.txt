QSL 卡片工坊 1.10.5
业余无线电双面通联确认卡编辑器

双击安装包，在 Windows 请求管理员权限时确认。可选任意盘上的可写安装目录。
覆盖升级前请关闭 QSL 卡片工坊。向导会优先采用原安装目录。
卸载默认清除应用设置、台站资料和标志缓存。可在卸载的组件页取消勾选。
旧版本卸载后如有残留资料，可在安装的组件页选择「从空白状态开始」。
已另存的 .qslcard、.qslmaterial 工程和导出文件可继续使用。
首次启动后，在主窗口右下角选择「用户手册」或按 F1 阅读操作说明。

主要使用环境为 Windows 10 和 Windows 11。编辑、保存和导出可离线使用。
旧系统构建目标为 Windows XP SP3（32 位）及 .NET Framework 4.0。此版本未在 Windows XP 实机上验证。
如需安装 .NET Framework 4.0，请通过 Microsoft 下载中心获取安装程序。
